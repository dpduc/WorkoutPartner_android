# Offline-first with background sync

Completed Sets and Tallies must save reliably even with no or bad connectivity — pose tracking itself runs entirely on-device, so requiring a live connection just to save the result would make the app worse than the camera work it's built on. We chose to keep Room as the on-device source of truth during and immediately after a workout, syncing to Firestore in the background once the device is online, over requiring an active connection to save (simpler, but fails exactly when a phone at a gym has weak signal). The trade-off is added complexity: a sync queue, conflict handling for the same Account signed in on multiple devices, and reconciling local Guest data against server data on migration (see [[0004-guest-to-account-migration]]).
